Dynamic app permissions
=======================
Noon.exe and app EXEs generated by --gui inherit highestAvailable:
- Administrator account: Windows requests UAC consent to elevate.
- Standard/Guest account: run with current account rights, without requiring admin credentials.
- Already elevated: no extra elevation prompt.
Guest/domain policies can still restrict execution or folder access.
This setting does not grant write access to folders the account cannot modify.
Setup and Uninstall.bat continue to request administrator privileges as configured.
Rebuild the main solution and regenerate older child EXEs to apply this change.
Toolchain baseline remains VS2019/v142, Windows SDK 10.0.19041.0.
